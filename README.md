## Overview

Soundtoys Little AlterBoy is an intuitive vocal pitch and formant shifter delivering gender-bending, robot, and creative pitch transformations with a straightforward three-knob interface.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Soundtoys Little AlterBoy** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Pitch Shift** | Independent pitch shifting up to ±12 semitones from original |
| **Formant Shift** | Independent formant shifting for gender and character transformation |
| **Robot Mode** | Quantize pitch to exact semitones for robotic vocal effect |
| **Drive** | Drive control adds saturation and character to the processed signal |
